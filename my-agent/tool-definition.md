# 도구 정의서 — 온담이 (ONDAM)

도구마다 다섯 항목을 채운다. **이름 / 쓰는 때·안 쓰는 때 / 인자 스키마 / 반환 형식 / 실패 뒤 행동**

표시: **(현행)** 지금 그렇게 동작함 · **(설계)** 이 문서에서 정했고 아직 반영하지 않음

온담이 리치메뉴는 여섯 개(건강 정보 · 약 정보 · 오늘 날씨 · 말동무 · 버스·지하철 · 긴급도움)다.
이 정의서는 그중 **넷**을 다룬다. 건강 정보와 말동무는 제외했다.
말동무는 도구를 부르지 않아 계약 틀이 맞지 않고, 건강 정보는 의료 판단 경계를 따로 그어야 한다.

**답변에 종결 표시를 붙이지 않는다.** 온담이는 대화형이라 답이 온 것 자체가 끝이다.
말이 필요한 것은 **답이 없는 경로**다 — 취소·실패·거절·보류. 아래 실패 표가 그 자리를 정한다.

## 도구 1. 날씨·미세먼지

### 이름 / 한 문장

`날씨_확인` — 보낸 위치의 하늘 상태·기온·미세먼지를 확인해 알려준다.

### 쓰는 때 / 안 쓰는 때

| | |
|---|---|
| **쓰는 때** | 리치메뉴 [오늘 날씨] → [위치보내기] → 위치가 들어왔을 때 **(현행)** |
| | 자판으로 "오늘 날씨", "미세먼지 어때" 라고 물었을 때 **(현행)** |
| **안 쓰는 때** | 위치가 아직 없을 때 → 부르지 않고 [위치보내기]를 먼저 띄운다 |
| | 받은 기간을 넘긴 질문 → 오늘 값으로 다음 주를 말하지 않는다. 다시 조회한다 |
| | "나가도 될까요?" 같은 몸 상태 전제 판단 → 의료 판단이므로 부르지 않는다 |

### 인자 스키마

| 인자 | 필수 | 자료형 | 허용값 | 누락 시 |
|---|---|---|---|---|
| 위도 | 필수 | 실수 | -90 ~ 90 | 부르지 않고 위치 요청 |
| 경도 | 필수 | 실수 | -180 ~ 180 | 부르지 않고 위치 요청 |
| 기간 | 선택 | 문자 | 오늘 / 이번주 / 다음주 | 기본값 "오늘" |

### 반환 형식

**답변에 인용할 최소 필드만 받는다.**

- 하늘 상태 / 기온 / 미세먼지 등급 / 확인 시각

**넘기지 않는다** — 시간별 전체 배열, 관측소 코드, 좌표, API 원본 응답 **(설계)**

**숫자를 그대로 내보내지 않는다.** 등급과 행동 권고로 바꾼다.

| 미세먼지 | 이렇게 말한다 |
|---|---|
| 좋음 | 공기가 깨끗해요. 나들이 다녀오셔도 좋겠어요 |
| 보통 | 괜찮습니다. 평소처럼 다니셔도 돼요 |
| 나쁨 | 조금 나쁩니다. 나가실 때 마스크 쓰세요 |
| 매우 나쁨 | 많이 나쁩니다. 오늘은 되도록 안에 계시는 게 좋겠어요 |

### 실패 뒤 행동

| 상황 | 행동 |
|---|---|
| 위치를 안 보내고 취소 | 재시도 없음. "괜찮아요, 아무 일도 없었어요" **(설계 — 현행 무응답)** |
| 응답 없음 / 시간 초과 | **1회만** 재시도 → 실패 시 "지금 확인이 안 됩니다 ❌" **(설계)** |
| 미세먼지 값만 빠짐 | 있는 것만 말한다. **날씨로 미세먼지를 짐작하지 않는다** **(설계)** |
| 좌표가 국내 밖 | 재시도하지 않는다. "국내 날씨만 알려드릴 수 있어요 ❌" **(설계)** |

## 도구 2. 버스 도착

### 이름 / 한 문장

`버스_도착_확인` — 보낸 위치에서 가까운 정류장을 찾고, 버스가 언제 오는지 알려준다.

### 쓰는 때 / 안 쓰는 때

| | |
|---|---|
| **쓰는 때** | 리치메뉴 [버스·지하철] → [위치보내기] → 위치가 들어왔을 때 **(현행)** |
| | 자판으로 "버스 언제 와" 라고 물었을 때 **(현행)** |
| **안 쓰는 때** | 위치가 아직 없을 때 → 부르지 않고 [위치보내기]를 먼저 띄운다 |
| | 노선 전체 경로나 요금을 물을 때 → 이 도구가 아니다 |
| | 며칠 뒤 버스 시간 → 실시간 도착 정보는 지금 것만 있다. 시간표가 아니다 |

### 인자 스키마

| 인자 | 필수 | 자료형 | 허용값 | 누락 시 |
|---|---|---|---|---|
| 위도 | 필수 | 실수 | -90 ~ 90 | 부르지 않고 위치 요청 |
| 경도 | 필수 | 실수 | -180 ~ 180 | 부르지 않고 위치 요청 |
| 반경 | 선택 | 정수(m) | 100 ~ 1000, 기본 500 | 기본값 사용 **(설계)** |

### 반환 형식

- 정류장 이름 / 노선 번호 / 도착까지 남은 시간 / **확인 시각**

**넘기지 않는다** — 차량 번호, 좌표, 내부 식별자, API 원본 응답 **(설계)**

**확인 시각을 반드시 붙인다.** 버스 정보는 1~2분 만에 바뀐다.

> ✗ 3분 뒤에 옵니다
> ✓ 지금 3분 뒤에 와요 (오후 2시 15분 확인)

### 실패 뒤 행동

| 상황 | 행동 |
|---|---|
| 위치를 안 보내고 취소 | 재시도 없음. "괜찮아요, 아무 일도 없었어요" **(설계 — 현행 무응답)** |
| 응답 없음 / 시간 초과 | **1회만** 재시도 → 실패 시 "지금 확인이 안 됩니다 ❌" **(설계)** |
| **도착 정보 0건** | **오류가 아닐 수 있다.** 두 경우를 구분한다 **(설계)**<br>· 막차 이후 → "오늘은 버스가 끊겼어요 ❌"<br>· 그 외 → "지금 확인이 안 됩니다 ❌" |
| 근처 정류장이 여럿 | 가장 가까운 하나를 먼저 보여준다. 열린 질문으로 되묻지 않는다 |

**막차를 따로 둔 이유** — 둘 다 "정보가 없다"지만 어르신이 할 일이 정반대다.
막차가 끊겼는데 "확인이 안 됩니다"라고 하면, 오지 않을 버스를 정류장에서 기다리시게 된다.

## 도구 3. 근처 약국 찾기

### 이름 / 한 문장

`근처_약국_찾기` — 보낸 위치를 기준으로 가까운 약국의 이름·주소·전화번호를 찾아 준다.

### 쓰는 때 / 안 쓰는 때

| | |
|---|---|
| **쓰는 때** | 리치메뉴 [약 정보] → [근처 약국 찾기] → 위치가 들어왔을 때 **(현행)** |
| | 자판으로 "근처 약국", "약국 어디" 라고 물었을 때 **(현행)** |
| **안 쓰는 때** | 위치가 아직 없을 때 → 부르지 않고 [위치보내기]를 먼저 띄운다 **(현행)** |
| | **특정 약국이 지금 문을 열었는지** → 부르지 않는다. 전화로 넘긴다 **(현행)** |
| | 약 이름·복용법·부작용 → 이 도구가 아니다. 의료 판단은 거절 범위 |

### 인자 스키마

| 인자 | 필수 | 자료형 | 허용값 | 누락 시 |
|---|---|---|---|---|
| 위도 | 필수 | 실수 | -90 ~ 90 | 부르지 않고 위치 요청 |
| 경도 | 필수 | 실수 | -180 ~ 180 | 부르지 않고 위치 요청 |
| 반경 | 선택 | 정수(m) | 500 ~ 3000, 기본 1000 | 기본값 사용 **(설계)** |

### 반환 형식

- 약국 이름 / 주소 / 전화번호 / 거리(m)

**넘기지 않는다** — 사업자등록번호, 좌표, 내부 식별자, API 원본 응답 **(설계)**

**영업시간은 값을 받더라도 답변에 확정으로 쓰지 않는다.** **(현행)**
임시휴무·명절·점심시간 때문에 자주 틀리기 때문이다. 전화로 넘긴다.

### 실패 뒤 행동

| 상황 | 행동 |
|---|---|
| 위치를 안 보내고 취소 | 재시도 없음. "괜찮아요, 아무 일도 없었어요" **(설계 — 현행 무응답)** |
| 응답 없음 / 시간 초과 | **1회만** 재시도 → 실패 시 "지금 확인이 안 됩니다 ❌" **(설계)** |
| 결과 0건 | 반경을 3000m로 한 번 넓혀 재조회 → 그래도 없으면 "근처에는 못 찾았어요 ❌" **(설계)** |
| 좌표가 국내 밖 | 재시도하지 않는다. "국내 약국만 찾을 수 있어요 ❌" **(설계)** |

## 도구 4. 긴급도움 — 보호자에게 알리기

**이 정의서에서 유일한 쓰기 도구다.** 한 번 나간 알림은 되돌릴 수 없다.

### 이름 / 한 문장

`긴급도움_보호자_알림` — 어르신이 도움을 요청하면, 등록된 보호자에게 알림을 보낸다.

### 쓰는 때 / 안 쓰는 때

| | |
|---|---|
| **쓰는 때** | 리치메뉴 [긴급도움]을 누른 **즉시**. 위치를 기다리지 않는다 **(현행)** |
| | 다시 누를 때마다 **매번** 부른다. 횟수 제한을 두지 않는다 **(현행 유지)** |
| **안 쓰는 때** | 대화 중 "아파요", "힘들어요" 같은 말만으로는 부르지 않는다 **(설계)** |
| | → 위급 여부를 모델이 판단하지 않는다. [긴급도움]이 있다고 안내만 한다 |
| | **119는 온담이가 걸지 않는다.** 버튼을 보여줄 뿐, 누르는 것은 사람이다 **(현행)** |

### 인자 스키마

| 인자 | 필수 | 자료형 | 허용값 | 누락 시 |
|---|---|---|---|---|
| 보호자 | 필수 | 등록된 보호자 | **미리 등록된 사람만** | 보낼 곳이 없다. 119 버튼을 크게 보여준다 **(설계)** |
| 위도 | **선택** | 실수 | -90 ~ 90 | 없어도 알림은 보낸다 **(현행)** |
| 경도 | **선택** | 실수 | -180 ~ 180 | 없어도 알림은 보낸다 **(현행)** |

**위치를 선택으로 둔 것이 이 도구의 핵심이다.**
필수로 두면 지도를 다루기 어려우신 분은 영영 도움을 요청하지 못한다.

### 반환 형식

- 보냈는지 여부 / 보낸 시각 / 알림을 받은 보호자 이름

**넘기지 않는다** — 보호자 전화번호 전체, 내부 식별자, API 원본 응답 **(설계)**

### 권한과 승인

| | |
|---|---|
| 구분 | **쓰기** — 바깥 세상이 바뀐다 |
| 사람 승인 | **두지 않는다.** 의도된 선택이다 |
| 근거 | 급할 때 "정말 보낼까요?"를 묻는 것이 더 위험하다. **못 보내는 것이 잘못 보내는 것보다 나쁘다** |
| 대신 두는 것 | 승인을 **앞**이 아니라 **뒤**에 둔다 → [잘못 눌렀어요] 버튼 + 요청 횟수 알림 |

### 실패 뒤 행동

| 상황 | 행동 |
|---|---|
| **잘못 눌렀음** | 알림은 이미 나갔다. 되돌리는 대신 **정정을 보낸다.**<br>[잘못 눌렀어요] → 보호자에게 "괜찮으시답니다" 후속 메시지 **(설계)** |
| **다시 누름** | **막지 않는다. 매번 보낸다** **(현행 유지)**<br>답만 다르게 한다 → "김○○님께 다시 알렸어요. 잘 전달됐습니다.<br>곧 연락하실 거예요. 편한 데 앉아서 기다려 주세요" **(설계)**<br>**어르신께 횟수는 말하지 않는다.** 세는 말은 나무라는 말로 들린다<br>보호자 알림에만 "2번째 요청"을 붙인다 **(설계)** |
| 알림 전송 실패 | 즉시 **1회** 재시도 → 실패 시 "보호자에게 연락이 안 됩니다 ❌" + **119 버튼을 가장 크게** **(설계)** |
| 위치만 취소함 | 알림은 이미 갔으므로 위험하지 않다. "보호자에게는 알렸어요. 위치는 아직 못 보냈어요" **(설계)** |
| 보호자 미등록 | 보낼 곳이 없다. "보호자가 등록되지 않았어요. 아래 119 버튼을 눌러주세요" **(설계)** |

### 현행 흐름과 답변 문구

```
① 리치메뉴 [긴급도움]
   → 이 시점에 보호자에게 알림이 이미 나간다 ★
② "온담아 도와주세요"
③ 걱정마세요. 보호자에게 즉시 연락했어요.
   위치를 보내주시면 더 빠르게 도와드릴 수 있어요.
   [ 위치보내기 ] [ 119 전화 ] [ 도움말 ]
④ 지도에서 [보내기] → 보호자에게 위치가 추가 전달
⑤ 보호자에게 바로 알렸어요. 잠시만 기다려 주세요.
   119가 필요하시면 아래 버튼을 눌러주세요.
   [ 119 전화 ]
```

**119 버튼이 ③과 ⑤ 양쪽에 있다.** 위치를 보냈든 안 보냈든 119로 가는 길이 늘 열려 있다.
③에만 없었다면, 지도를 다루기 어려우신 분 — 가장 위험한 분 — 이 119 버튼을 못 보셨을 것이다.

## 네 도구를 한눈에

| 도구 | 구분 | 승인 | 재시도 | 그 도구만의 규칙 |
|---|---|---|---|---|
| 날씨·미세먼지 | 읽기 | 불필요 | 1회 | 숫자를 **등급과 행동 권고**로 바꿔 전달 |
| 버스 도착 | 읽기 | 불필요 | 1회 | **확인 시각** 필수 + **막차와 오류를 구분** |
| 근처 약국 | 읽기 | 불필요 | 1회 | 영업 여부를 **확정하지 않고 전화로 이관** |
| 긴급도움 | **쓰기** | **없음(의도)** | **제한 없음** | 위치가 **선택** 인자 + 요청 횟수를 알림 |

경계가 겹치지 않는지 확인하는 지점:

- 셋 다 위치를 받지만 **반경이 다르다** — 버스 500m, 약국 1000m, 날씨는 지역 단위
- 약국은 **영업시간을 책임지지 않는다** — 전화가 그 자리를 대신한다
- 긴급도움만 위치가 **선택**이다 — 나머지 셋은 위치가 없으면 아예 부르지 않는다
